# Changelog

## Unreleased

- Added native user-window definition, selection, and cancellation APIs.
- Added a focused `UserWindows` example and webcam HIL test.

## 1.1.0

- Added hardware-validated graphics support for the GU112X16G-7003.
- Added friendly row-major `drawBitmap_P(x, y, width, height, data)` API.
- Added explicit native bitmap APIs for RAM and PROGMEM.
- Added `setCharacterSpacing()`.
- Added `reverse()`.
- Added `screenMode()`.
- Added tested 112x16 display geometry constants.
- Added `GraphicsShowcase` example.
- Preserved the original text/control API and 38400-baud serial behavior.
